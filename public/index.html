Nginx

Coba ubah halaman ini

  1. Buka public/index.html di GitHub.
  2. Ubah teks atau tampilan website.
  3. Simpan perubahan dengan Commit Changes.
  4. GitHub mengirim notifikasi ke Jenkins.
  5. Jenkins menjalankan pipeline dan deploy ke VPS.
